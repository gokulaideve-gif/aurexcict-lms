# AUREXCICT LMS - Deployment Guide

## TECHTAMIZHA - AUREX26 Hackathon

### Zero Cost Stack
- **Vercel**: Hosting (100GB free)
- **Supabase**: Postgres DB + Auth + Realtime (500MB free)
- **Cloudinary**: Media Storage (25GB free)
- **LiveKit**: Live Streaming (1000 mins free)
- **Sarvam AI**: Tamil AI (free credits)
- **Groq AI**: Fallback AI (free)

### Deployment Steps
1. Push to GitHub: tech-tamizha/aurexcictlms
2. Connect to Vercel
3. Add environment variables
4. Create Supabase project + run schema
5. Create Cloudinary unsigned preset
6. Create LiveKit project
7. Add custom domain aurexcictlms.in
