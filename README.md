# AUREXCICT LMS - TECHTAMIZHA
## AUREX26 Hackathon - CICT Chennai - Ministry of Education

**One Design System, Three Different Experiences, Zero Cost for CICT**

### Stack
- Next.js 14 App Router
- Supabase (Auth + Postgres + Realtime + Storage)
- Cloudinary (Media Storage)
- LiveKit (Free Live Streaming)
- Sarvam AI + Groq AI (Tamil AI Tutor)
- Vercel Deployment

### Features
- Admin Control Center (Data-dense tables, charts)
- Organizer Studio (Course builder, drag-drop)
- Learner App (Duolingo-like mobile-first)
- Free Live Streaming with auto attendance
- Tamil OCR + AI Tutor
- Certificate generation with QR codes

### Setup
1. npm install
2. Copy .env.local from .env.example
3. npm run dev

### Database Schema
Run SQL in Supabase SQL Editor (see docs/database-schema.sql)
